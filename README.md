# Домашняя работа по введению в Джанго

Все настройки проекта находятся в папке config в модуле settings.py

## Краткое описание проекта

Выполняет функционал в соответствии с ТЗ домашних работ. 
Все настройки проекта в папке config

В проекте одно приложение catalog в рамках которого выполнены несколько html страниц:

    - contacts.html

    - home.html

находятся в папке 

'''catalog/templates'''

## Работа с Базами Данных

Работа с базами данных реализована с помощью postgresql_psycopg2

### Защита данных

с целью сохранения конфеденциальной информации все настройки сохраняются в файле .env который не передаётся в репозиторий
в файле sample.dotenv вы можете увидеть пример оформления файла и какие требуются данные

## Установка и использование

### Требования к окружению

Для использования программы требуется установить на компьютер python v 3.8 и выше

### Установка проекта

Склонировать репозиторий:

    '''
    git clone https://github.com/KharitonovAM/Start_to_django
    '''


Создать и активировать виртуальное окружение:

       ```

       poetry shell


       ```
Установить зависимости

       ```

        poetry init

       ```
Запуск проекта

       ```

        poetry run python

       ```
